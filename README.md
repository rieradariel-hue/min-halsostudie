
## Översikt
Detta projekt analyserar data från en hälsostudie med 800 personer.  
Del 1: Grundläggande statistik och grafer.  
Del 2: Refaktorering med funktioner, klasser och linjär regression.

## Python-version
Python 3.13.7

## Struktur
- `data/`: Dataset (health_study_dataset.csv)
- `src/`: Funktioner och klasser (stats_utils.py, health_analyzer.py, viz_utils.py)
- `del1.ipynb`: Grundanalys
- `del2.ipynb`: Refactoring + regression
